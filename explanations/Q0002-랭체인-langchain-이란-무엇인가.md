# Q0002 · 랭체인(LangChain)이란 무엇인가?

- **태그**: concept
- **날짜**: 2026-06-27

## ❓ 질문
랭체인(LangChain)이란 무엇인가?

## 💡 한 줄 답
> LLM을 활용한 애플리케이션을 쉽게 만들도록 도와주는 **오픈소스 프레임워크**.
> 모델, 프롬프트, 검색(RAG), 메모리, 에이전트 같은 부품을 **레고처럼 조립(chain)**하게 해준다.

## 📖 설명

이름 그대로 `Lang`(언어 모델) + `Chain`(연결)이다. LLM을 그냥 채팅하듯 한 번 호출하는 것을 넘어,
**여러 부품을 연결해 더 똑똑한 AI 앱**을 만들도록 돕는 도구 모음이다.

**왜 필요한가?** LLM 단독으로는 한계가 있다.
- 학습하지 않은 최신 정보, 사내 문서를 모른다 (→ [[Q0001-rag는-왜-필요한가]]).
- 외부 도구(검색, 계산기, DB)를 스스로 쓰지 못한다.
- 긴 대화의 맥락 관리가 번거롭다.

랭체인은 이 빈틈을 메우는 **연결고리** 역할을 한다.

### 핵심 구성 요소

| 구성 요소 | 역할 |
|---|---|
| **Models** | OpenAI, Claude, DeepSeek 등 다양한 LLM을 동일한 방식으로 호출 |
| **Prompts** | 프롬프트를 템플릿으로 관리 |
| **Chains** | 여러 단계를 순서대로 연결 (입력 → 처리 → 출력) |
| **Retrieval** | 외부 문서를 검색해 LLM에 넣어줌 → **이게 바로 RAG** |
| **Memory** | 이전 대화 내용을 기억 |
| **Agents** | LLM이 스스로 도구를 골라 사용 (→ [[Q0003-랭체인은-agent-개발용-프레임워크인가-chain-vs-agent]]) |

### 이 프로젝트(RAG)와의 관계

지금 공부하는 RAG에서 랭체인이 중요한 이유는 **Retrieval** 부분이다.

```
질문 → [문서 검색(Retrieval)] → 관련 문서 찾기 → LLM에 함께 전달 → 정확한 답변
```

"내 문서/데이터를 LLM에 연결"하는 RAG 파이프라인을, 랭체인이 벡터DB(예: Neo4j), 임베딩, LLM을
**조립 가능한 블록**으로 제공해 쉽게 구성하게 해준다.
