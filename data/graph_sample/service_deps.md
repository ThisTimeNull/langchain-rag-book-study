# (가상) 서비스 의존 관계

- 결제 API는 인증 서비스에 의존한다.
- 추천 엔진는 결제 API에 의존한다.
- 알림 서비스는 추천 엔진에 의존한다.
- 사용자 DB는 알림 서비스에 의존한다.
- 검색 인덱서는 사용자 DB에 의존한다.
- 정산 배치는 검색 인덱서에 의존한다.
- 정산 배치는 결제 API에 의존한다.
- 세션 스토어는 정산 배치에 의존한다.
- 로그 수집기는 세션 스토어에 의존한다.
- 이미지 CDN는 로그 수집기에 의존한다.
- 이미지 CDN는 사용자 DB에 의존한다.
- 쿠폰 엔진는 이미지 CDN에 의존한다.
- 배송 추적는 쿠폰 엔진에 의존한다.
- 리뷰 서비스는 배송 추적에 의존한다.
- 리뷰 서비스는 세션 스토어에 의존한다.
- 가맹점 포털는 리뷰 서비스에 의존한다.
- 재고 관리는 가맹점 포털에 의존한다.
- 메시지 큐는 재고 관리에 의존한다.
- 메시지 큐는 쿠폰 엔진에 의존한다.
- 환율 서비스는 메시지 큐에 의존한다.
- 감사 로그는 환율 서비스에 의존한다.
- 피처 스토어는 감사 로그에 의존한다.
- 피처 스토어는 가맹점 포털에 의존한다.
- A/B 테스트는 피처 스토어에 의존한다.
